# Get offline token

1. Navigate to https://console.redhat.com OR [Token direct](https://console.redhat.com/ansible/automation-hub/token)
2. Upper left corner dropdown `Red Hat Hybrid Cloud Console` 
3. Click and Select `Ansible Automation Platform`
4. Left side list Select `Automation Hub`
5. Select `Connect to Hub`
6. Observe the `Offline token` - either a value to copy/paste into OR Click on the button to retreive a token
